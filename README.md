# ParaElys

Official personal website and link hub for ParaElys.

Live site: https://paraelys.github.io/ParaElys/

## Features

- Responsive desktop and mobile layouts
- Russian, English, Ukrainian and Kazakh interface
- Animated cosmic background with a lighter mobile mode
- Social links and support services
- Collaboration contact tools
- Local SVG brand icons and flags
- SEO metadata, sitemap and robots.txt
- Strict Content Security Policy
- Remembered language and layout preferences

## Structure

- `index.html` — page markup and metadata
- `styles.css` — visual design, responsive layout and animation
- `script.js` — interactions, translations and particle animation
- `background.png` — main ParaElys background artwork
- `favicon-pe.png` — site favicon
- `icons/` — local service and language icons
